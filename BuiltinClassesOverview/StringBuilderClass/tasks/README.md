## Tasks

Below are the tasks requirements and examples of input data to be provided for the different programs and expected outputs.

### DigitsLettersOthers

Read a line of text and split its characters into three groups:

- digits
- letters
- all other characters

Print each group on a separate line in the same order in which the characters appear in the input.

Test inputs and outputs:

```
Input:
Hello123 World 45.

Output:
12345
HelloWorld
  .
```
