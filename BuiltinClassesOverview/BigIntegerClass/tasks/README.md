# About

Contains info about solving the tasks.

## Tasks

Below are the tasks requirements and examples of input data to be provided for the different programs and expected outputs.

### SumBigNumbers

Read two very large whole numbers and print their sum.

Because the numbers may be too large for `int` or `long`, use `BigInteger`.

Test inputs and outputs:

```
Input:
423234234256
6345856756345

Output:
6769090990601
```

### BigFactorial

Read an integer `n` and print `n!`.

The result can become very large, so store the factorial result in a `BigInteger`.

Test inputs and outputs:

```
Input:
23

Output:
25852016738884976640000
```
